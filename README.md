# غين — الملف التعريفي ولوحة العقود | Gain

الملف التعريفي لشركة «غين لتقنية المعلومات» — منصة تشغيل صحية موحّدة للعيادات والمجمعات الطبية — إضافة إلى نظام العقود الإلكترونية ولوحة إدارتها.

## التشغيل

الموقع ثابت بالكامل (HTML/CSS/JS) بلا أي اعتماديات خارجية أو خادم. للتشغيل محليًا:

```bash
python -m http.server 8899
```

ثم افتح `http://localhost:8899` — أو انشر الملفات كما هي على أي استضافة ثابتة (GitHub Pages).

## لوحة العقود — دليل الموظف

اللوحة بالعربية بالكامل وتعمل من المتصفح مباشرة. أقسامها:

### 1) الرئيسية
- **بطاقات سريعة:** إجمالي العقود، العقود التي تنتهي خلال 30 يومًا، والمسودات.
- **تنبيه أصفر** يظهر تلقائيًا بأسماء العقود القريبة من الانتهاء.
- **جدول العقود** مع بحث (اسم العميل / رقم العقد) وفلاتر (الحالة، تاريخ الإنشاء). اضغط أي صف لفتح صفحة العقد.
- **حالات العقد:** مسودة (رمادي) ← قيد المراجعة (أصفر، أُرسل رابطه للعميل) ← موقّع (أخضر) ← منتهي (أحمر، يُحسب تلقائيًا من تاريخ الانتهاء).

### 2) عقد جديد (معالج من 4 خطوات)
1. **نوع العقد** — حاليًا: عقد خدمات نظام غين (والبنية جاهزة لقوالب أخرى).
2. **بيانات العقد** — اسم المنشأة وتاريخ البدء (إلزاميان) وبقية البيانات اختيارية يكمّلها العميل، مع شرح تحت كل حقل. ويمكن إضافة **خصم** (نسبة مئوية أو مبلغ ثابت لكل دورة، مع سبب اختياري يظهر للعميل) — تظهر لك معاينة فورية: الأصلي ← الخصم ← بعد الخصم ← الضريبة (تُحسب بعد الخصم) ← الإجمالي، والخصم يُجمّد في رابط العقد فلا يتأثر بتغيير الأسعار لاحقًا ولا يستطيع العميل تعديله.
3. **المعاينة** — العقد كما سيراه العميل تمامًا، بالأسعار والبنود المعتمدة.
4. **الإرسال** — توليد رابط العقد (مع كلمة مرور اختيارية تشفّره بالكامل)، نسخه وإرساله للعميل.

يُحفظ تقدمك تلقائيًا **كمسودة** في كل خطوة — يمكنك الخروج والعودة لاحقًا من الرئيسية.

### 3) صفحة العقد (التفاصيل)
نسخ/فتح رابط العقد، تعديل تاريخي البدء والانتهاء (الانتهاء يُحسب تلقائيًا: سنة من البدء)، تغيير الحالة، **استيراد النسخة الموقّعة**، **تنزيل نسخة Word (DOCX)** من العقد (تشمل بيانات العميل وتوقيعه إن استُوردت نسخته الموقّعة)، أو حذف العقد.

### 4) الإعدادات
- **الأسعار:** الاشتراك الأساسي، تطبيق غين، ونسبة الضريبة — تنعكس على كل عقد جديد.
- **بنود العقد:** حرّر أي بند مباشرة، ثم «حفظ كأساس» ليعتمد في كل العقود الجديدة، أو «إعادة الضبط للأصل».
- **النسخة الاحتياطية:** بيانات اللوحة محفوظة في متصفحك فقط — نزّل نسخة احتياطية دوريًا، واستعدها عند تغيير الجهاز.

### دورة العقد كاملة
1. أنشئ العقد من المعالج وأرسل الرابط للعميل (وكلمة المرور في رسالة منفصلة إن وُجدت).
2. يفتح العميل الرابط، يعبّئ بياناته، يوافق على البنود، يوقّع بإصبعه أو الفأرة، ويحفظ PDF لنفسه.
3. يضغط العميل «تصدير النسخة الموقّعة» ويرسل لك الملف الناتج.
4. من صفحة العقد في اللوحة اضغط «استيراد النسخة الموقّعة» — تصبح الحالة «موقّعًا» ويُحفظ التوقيع.
5. قبل انتهاء العقد بثلاثين يومًا ستجد تنبيهًا في الرئيسية لتجديد التواصل مع العميل.

> **ملاحظة مهمة:** لا يوجد خادم — كل البيانات في متصفح الموظف، وبيانات العميل في متصفحه. النسخة الاحتياطية هي صمام الأمان الوحيد؛ نزّلها دوريًا.

## مزايا الملف التعريفي

- **عرض الشرائح:** تنقّل بلوحة المفاتيح، ملء الشاشة، فهرس شرائح، تصدير PDF عالي الجودة (1920×1080 لكل صفحة)
- **التجربة التفاعلية:** مشاهد مثبّتة تُفرك بالتمرير (تبديل المنتجات، رحلة المريض برمز متحرك، جولة الأدوار)، عدّادات وأسلاك تكامل تُرسم مع التمرير
- **بدون اعتماديات خارجية:** الخطوط (Cairo/Tajawal) والأيقونات ومكتبة Word مضمّنة محليًا — يعمل بدون إنترنت
- **RTL بالكامل** وبهوية غين البصرية
