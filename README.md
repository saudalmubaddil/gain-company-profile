# غين — الملف التعريفي | Gain Company Profile

الملف التعريفي لشركة «غين لتقنية المعلومات» — منصة تشغيل صحية موحّدة للعيادات والمجمعات الطبية.

## الصفحات

| الصفحة | الوصف |
|---|---|
| [`index.html`](index.html) | صفحة الهبوط — بوابة الدخول للعرضين |
| [`slides.html`](slides.html) | العرض التقديمي — 25 شريحة مع تنقّل بالأسهم وتصدير PDF |
| [`interactive.html`](interactive.html) | التجربة التفاعلية — صفحة تمرير بمشاهد مربوطة بالتمرير |

## المزايا

- **عرض الشرائح:** تنقّل بلوحة المفاتيح، ملء الشاشة، فهرس شرائح، تصدير PDF عالي الجودة (1920×1080 لكل صفحة)
- **التجربة التفاعلية:** مشاهد مثبّتة تُفرك بالتمرير (تبديل المنتجات، رحلة المريض برمز متحرك، جولة الأدوار)، عدّادات وأسلاك تكامل تُرسم مع التمرير
- **بدون اعتماديات خارجية:** الخطوط (Cairo/Tajawal) والأيقونات مضمّنة محلياً — يعمل بدون إنترنت
- **RTL بالكامل** وبهوية غين البصرية
